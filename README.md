# Libro Digital Editable

Este proyecto es una aplicación web interactiva que permite crear, editar y personalizar un libro digital. Utiliza **Tailwind CSS** para el diseño y ofrece una experiencia visual atractiva con efectos como glassmorphism y gradientes animados.

## Características

- **Edición de contenido**: Escribe y edita texto directamente en las páginas del libro.
- **Portada personalizada**: Incluye una portada editable con opciones de diseño únicas.
- **Imágenes decorativas**: Agrega imágenes a las páginas y personaliza su contenido visual.
- **Navegación intuitiva**: Cambia de página con botones, clics en los bordes o las flechas del teclado.
- **Persistencia local**: Guarda automáticamente el contenido en el almacenamiento local del navegador.

## Tecnologías utilizadas

- **HTML5** y **JavaScript** para la estructura y funcionalidad.
- **Tailwind CSS** para el diseño y estilos personalizados.
- **AOS (Animate On Scroll)** para animaciones fluidas.
